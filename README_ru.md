# TeekasFigure

**GPU-ускоренная эволюционная аппроксимация изображений и видео с использованием геометрических фигур**

[🇬🇧 Read in English](README.md)

---

## Что такое TeekasFigure?

TeekasFigure воссоздаёт изображения и видео, последовательно накладывая геометрические фигуры (пользовательские PNG-текстуры) на холст с помощью эволюционного алгоритма. GPU (через WGPU/Vulkan/DX12) оценивает тысячи кандидатов параллельно, делая процесс невероятно быстрым и визуально впечатляющим.

Алгоритм эволюционирует популяцию фигур-кандидатов через турнирный отбор, мутацию и выживание сильнейших, создавая картины, напоминающие рисунки из геометрических мазков. В зависимости от настроек фигуры могут быть как полупрозрачными, так и полностью непрозрачными.

### Возможности

- **Эволюционный алгоритм** — Турнирный отбор, мутации, многопоколенческое уточнение
- **GPU-ускорение** — Compute-шейдеры оценивают тысячи кандидатов параллельно за доли секунды
- **Кастомные фигуры** — Используйте любой PNG как кисть (круги, квадраты, брызги, листья, логотипы, да хоть фото вашей любимой собачки!)
- **Режим разнообразия фигур** — Не даёт алгоритму «лениться» и использовать только одну идеальную форму
- **Визуализация в реальном времени** — Наблюдайте за созданием картины в 60 FPS
- **Поддержка видео (Демо)** — Экспериментальный режим с поддержанием временной когерентности. *Внимание: функция находится в стадии раннего тестирования, может работать нестабильно.*
- **Глубокая настройка** — Управление всеми аспектами эволюции через файл `settings.toml`

### Требования

- **Rust** 1.70+ ([rustup.rs](https://rustup.rs/))
- **GPU** с поддержкой Vulkan, DX12 или Metal
- **FFmpeg** (опционально, для работы с видео) — должен быть добавлен в PATH

### Быстрый старт

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/TeekasFigure.git
cd TeekasFigure

# Собрать релиз
cargo build --release

# Запустить
cargo run --release
```

### Структура папок

```text
TeekasFigure/
├── input_media/       ← Сюда кладёте целевое изображение (PNG/JPG/BMP) или видео (MP4)
├── raw_shapes/        ← Сюда складывайте ваши сырые картинки для фигур
├── input_shapes/      ← Отсюда программа читает готовые текстуры (не кладите сырые файлы сюда)
├── output/            ← Готовые работы сохраняются сюда
├── settings.toml      ← Файл настроек (создаётся автоматически)
└── TeekasFigure.exe   ← Приложение
```

### ⚠️ Подготовка кастомных фигур (Очень важно!)

**НЕ кладите свои картинки напрямую в папку `input_shapes/`!** Программа требует, чтобы фигуры были строго определённого формата (128x128, оттенки серого + альфа-канал). Если подсунуть ей обычные PNG, она их с огромной вероятностью не проглотит.

Вместо этого положите свои картинки (PNG, JPG, BMP, WebP) в папку `raw_shapes/` и запустите встроенный скрипт:

```bash
cargo run --example prepare_shapes
```
Этот скрипт сам обрежет, перекрасит и переложит готовые текстуры фигур в папку `input_shapes/`.

### Настройки (`settings.toml`)

Все параметры можно менять в файле `settings.toml`. Подробное описание каждого:

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| **`batch_size`** | 1000 | Количество кандидатов, генерируемых и оцениваемых за один проход на GPU (1-4096). |
| **`max_shapes`** | 4000 | Максимальное количество фигур на холсте, после которого программа остановится. |
| **`mutations_per_frame`** | 1 | Сколько фигур успешно ставится за один отрисованный кадр (при 60 FPS). |
| **`max_texture_size`** | 512 | Внутреннее разрешение, до которого будет сжато исходное изображение. |
| **`vram_budget_mb`** | 2048 | Лимит видеопамяти для массива текстур фигур. |
| **`scale_min`** | 0.02 | Минимально допустимый размер фигуры. |
| **`scale_max`** | 9.0 | Максимальный размер фигуры (применяется на старте генерации). |
| **`shape_resolution`** | 128 | Разрешение фигур (лучше не трогать, если не меняли скрипт подготовки). |
| **`mutations_per_shape`** | 1 | (Только видео) Количество попыток мутации для уже стоящей фигуры в новом кадре. |
| **`displacement_weight`** | 0.1 | (Только видео) Штраф за сильное смещение фигуры (предотвращает мерцание). |
| **`target_fps`** | 12 | (Только видео) До скольки FPS сжать исходное видео. |
| **`evolve_opacity`** | true | Если `true`, прозрачность фигур будет меняться алгоритмом. Если `false` — фигуры будут всегда полностью непрозрачными 100%. |
| **`num_generations`** | 6 | Количество поколений эволюции до выбора итоговой фигуры. |
| **`min_improvement`** | -0.5 | Минимальный порог улучшения MSE для принятия фигуры (отрицательное = улучшение). |
| **`use_min_improvement`** | true | Использовать ли порог `min_improvement`. Отключайте при использовании `diversity_mode`. |
| **`max_rejections`** | 50 | Количество неудачных попыток подряд до завершения работы (сходимость). |
| **`survival_rate`** | 0.10 | Доля популяции, выживающая в каждом поколении (например, 0.10 = 10%). |
| **`children_per_parent`** | 9 | Количество мутировавших копий от каждой выжившей фигуры. |
| **`diversity_mode`** | false | Включает режим разнообразия фигур. См. примечание ниже. |
| **`diversity_penalty_increment`**| 5.0 | Штраф, который дается фигуре каждый раз, когда она попадает на холст. |
| **`diversity_decay_enabled`**| true | Будут ли штрафы остальных фигур постепенно снижаться. |
| **`diversity_decay_amount`** | 0.01 | На сколько снимается штраф с неиспользуемых фигур каждый шаг. |

> **🔥 ВАЖНО ПРО РЕЖИМ РАЗНООБРАЗИЯ (DIVERSITY MODE):**
> Когда вы включаете `diversity_mode = true`, алгоритм начинает искусственно добавлять штрафные баллы часто используемым фигурам. Из-за этого штрафа показатель "улучшения картинки" будет искажен. Поэтому **при включении Diversity Mode обязательно ставьте `use_min_improvement = false`**, иначе алгоритм просто начнет отклонять все фигуры подряд и зависнет.

### Управление

| Клавиша | Действие |
|---------|----------|
| `Пробел` | Пауза / Продолжить |
| `S` | Моментально сохранить картинку в папку output |
| `Escape` | Выход |
