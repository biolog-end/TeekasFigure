TeekasFigure → Minecraft Java 1.21.1 / Fabric / Java 21

Установи teekasfigure-mob-tools-0.1.4.jar в mods. Fabric API не нужен.
В одиночном мире: Escape → картинки мобов → Экспорт сверху или Экспорт лицом вперёд.
Набор сохранится в teekasfigure_exports/mobs_top_... или mobs_front_... рядом с saves.
В приложении: Minecraft / экспорт раскладки → импортировать мобов из Minecraft.
Выбери папку с mob_mapping.json, затем целевое фото/видео и запусти генерацию.
В игре: Escape → видео на мобах → выбрать scene.json из этого пакета.
Маппинг переносится автоматически. Datapack и Python не нужны.

Игра создаёт настоящих мобов и переносит игрока над сценой в креатив с полётом.
Доступны пауза, возврат камеры, перспектива и остановка.
Остановка удаляет сущности сеанса и восстанавливает позицию и режим игрока.
Поддерживается одиночный мир; звук и все варианты скинов не экспортируются.

scene.json: schema_version=1, canvas_px, fps, complete, frame_count, brushes.
frames.jsonl: frame_index, time_seconds, shapes. Координаты в пикселях;
начало слева сверху; x вправо, y вниз; поворот по часовой стрелке в радианах.
Порядок shapes снизу вверх; постоянный id сохраняется при движении.
brushes/: точные текстуры, использованные приложением.
minecraft_mapping.json: типы мобов и геометрия из импортированного набора.
complete=false: пакет не готов для проигрывания.
